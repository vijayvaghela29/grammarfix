# GrammarFix

GrammarFix is a privacy-focused AI grammar checker powered by Tether's QVAC SDK.

It checks and improves English grammar using an AI model running locally on the user's device. No cloud AI API or API key is required for grammar inference.

## Features

- Grammar correction
- Spelling correction
- Sentence improvement
- Correction explanation
- Local AI inference
- No external AI API key required

    ↓
GrammarFix web interface

Local Node.js server

Grammar correction
